# postgresql backup and restore

### pg_backup_cron.sh
Скрипт предназначен для автоматического резервного копирования баз данных PostgreSQL. Он создает отдельную папку для бэкапов для каждого дня недели (pgsql-Mon, pgsql-Tue и т.д.), обеспечивая таким образом 7-дневную ротацию бэкапов. Скрипт выполняет резервное копирование всех баз данных (за исключением шаблонных баз и системной базы 'postgres'), а также отдельно: ролей пользователей, глобальных объектов и схем. По окончанию бэкапа каждый раз создается символическая ссылка `latest`, указывающая на самый свежий бэкап. Для целей мониторинга в Zabbix скрипт записывает дату и размер последнего выполненного бэкапа. Скрипт поддерживает возможность использования peer-аутентификации, если это настроено.  

### crontab
Это фрагмент файла crontab, он настроен на ежедневный запуск скрипта `pg_backup_cron.sh` в 4:00 утра от имени пользователя `root`. Весь вывод скрипта (как стандартный вывод, так и ошибки) дописывается в файл `/var/log/pg_backup_cron.log`.

### pg_restore_menu.sh
Скрипт предоставляет интерактивное меню для восстановления баз данных PostgreSQL из резервных копий, созданных скриптом `pg_backup_cron.sh`.
Он позволяет пользователю:
1. Выбрать набор резервных копий для восстановления (на основе дня недели).
2. Выбрать конкретные базы данных для восстановления или восстановить все базы из выбранного набора.
3. Опционально перед восстановлением основного содержимого баз данных можно восстановить отдельно глобальные объекты (роли, табличные пространства и т.д.) или только роли.
   
Скрипт автоматически завершает активные подключения к базе данных перед восстановлением и проверяет наличие достаточного свободного места на диске. Скрипт может быть запущен пользователем `postgres` или `root` (в последнем случае он автоматически будет использовать `sudo -u postgres`).
